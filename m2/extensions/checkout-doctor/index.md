# Checkout Doctor

Checkout Doctor collects data about checkout sessions and errors to help you
find and fix problems in the checkout process. It provides following features:

 -  Step-by-step timeline of every checkout session
 -  Logs JavaScript, server and payment errors your customers hit
 -  Dashboard with abandonment, recovery rate and revenue at risk

This module is bundled into [Firecheckout extension](/m2/extensions/firecheckout/),
but can be installed separately.
