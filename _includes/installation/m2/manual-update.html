## Update Make sure the Marketplace module is installed and the artifacts directory is registered (see [Prepare to install](#prepare-to-install)), then: 1. Download the latest archive from your account page:{% if include.argentotheme != 'false' %} - [argentotheme.com](https://argentotheme.com/license/customer/activation/){% endif %}{% if include.firecheckout != 'false' %} - [firecheckout.net](https://firecheckout.net/license/customer/activation/){% endif %}{% if include.swissuplabs != 'false' %} - [swissuplabs.com](https://swissuplabs.com/license/customer/activation/){% endif %} 2. Unpack it to the `/vendor/swissup/artifacts` folder: ```bash unzip swissup..zip -d vendor/swissup/artifacts ``` 3. Run the update: ```bash composer update {{ include.package }} -w &&\ bin/magento setup:upgrade --safe-mode=1 &&\ bin/magento setup:di:compile &&\ bin/magento setup:static-content:deploy ``` {% include installation/m2/hyva-link.html anchor="update" %}
